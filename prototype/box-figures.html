Days sit with the stage: the track is drawn in days (7, 30, 100, 365), so 38 reads as somewhere on it. "Add another phone" matches "Add another box" in Settings, and the sheet it opens explains the rest.

Each number once

Hours in Settings, days on the box's page. Seen twice, they read like two figures that ought to agree, which the receipt already learned the hard way.

Every number says since when

"38 days" alone doesn't answer "since when?". With the date in the same line, there's nothing left to ask.

Days belong with the stage

The stage moves at 7, 30, 100 and 365 days. Putting the count next to the track lets someone place it without a "12 to go", which the stage deliberately never says.

Fewer boxes, not less said

The code sheet already says "Scan this with the other phone… It works for an hour." The page only needs a way to open it.
